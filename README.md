# English AI

Повноцінний MVP застосунку для вивчення англійської, натхненний механіками мовних тренажерів.

## Запуск

Потрібен Node.js 18+.

```bash
npm install
npm run dev
```

Після цього відкрий адресу, яку покаже Vite (зазвичай http://localhost:5173).

## Що вже працює

- курс із уроками та блокуванням наступних уроків;
- вправи з варіантами відповідей;
- перевірка відповідей;
- XP, рівні, серія днів;
- сердечка;
- кристали;
- магазин;
- профіль і статистика;
- досягнення;
- озвучення відповідей через SpeechSynthesis браузера;
- AI Tutor demo-чат;
- збереження прогресу в localStorage;
- адаптивний дизайн для телефону.
